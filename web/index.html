How these records are counted

Requests / calls treats each saved record as one unit across harnesses: Codex usage reports, Claude response messages, Copilot user requests, Antigravity generation calls, Grok completed events per model, OpenCode completed messages, and Cursor export rows. Copilot response rounds count the saved tool-call rounds separately. Missing token values stay unknown and contribute only to count metrics. Daily averages include days with no activity. Model transitions start a chapter when a new model has at least 3 records and 0.5% of requests in the selected range; boundaries are at least 7 days apart. These are records preserved on your devices, not billing or a complete account history.
